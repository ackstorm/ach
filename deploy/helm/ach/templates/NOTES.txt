=== REQUIRED: at-rest crypto Secrets ===

platform-api and the forwarder REFUSE TO START until these Secrets exist
(they are referenced by the `security` values block; the chart never creates
them, because they must stay STABLE across upgrades):

  kubectl -n {{ .Release.Namespace }} create secret generic {{ .Values.security.keyEncryptionKey.secretRef.name }} \
    --from-literal={{ .Values.security.keyEncryptionKey.secretRef.key }}="$(openssl rand -base64 32)"   # AES-256 DEK: base64 of 32 bytes
  kubectl -n {{ .Release.Namespace }} create secret generic {{ .Values.security.credentialHashPepper.secretRef.name }} \
    --from-literal={{ .Values.security.credentialHashPepper.secretRef.key }}="$(openssl rand -base64 32)"   # HMAC pepper

⚠  Rotating the DEK orphans all sealed LiteLLM key material; rotating the
   pepper invalidates every stored credential hash. Create once, keep stable.

=== IMPORTANT: CRD Upgrade Dance (D-03) ===

The 7 LiteLLM operator CRDs are shipped in the chart's crds/ directory and
are installed automatically by `helm install`. However, Helm does NOT manage
CRDs on `helm upgrade` (standard Helm 3 convention — avoids accidental data
loss on schema changes).

Before every `helm upgrade`, apply the CRDs manually:

  kubectl apply -f charts/ach/crds/
  # or, if installing from the OCI registry:
  helm pull oci://ghcr.io/ackstorm/charts/ach \
    --version {{ .Chart.Version }} --untar
  kubectl apply -f ach/crds/

Then run your upgrade:

  helm upgrade {{ .Release.Name }} oci://ghcr.io/ackstorm/charts/ach \
    --version {{ .Chart.Version }} --namespace {{ .Release.Namespace }}

=== Getting Started ===

Tip: For a fresh namespace, run:
  helm install ach ./charts/ach \
    --namespace <your-namespace> --create-namespace

1. Create a Secret with your LiteLLM master key:

  kubectl create secret generic litellm-master-key \
    --from-literal=LITELLM_MASTER_KEY=<your-master-key> \
    -n {{ .Values.watchNamespace }}

2. Create a LiteLLMConnection CR:

  kubectl apply -n {{ .Values.watchNamespace }} -f - <<EOF
  apiVersion: ach.ackstorm.ai/v1alpha1
  kind: LiteLLMConnection
  metadata:
    name: default
  spec:
    endpoint: http://litellm.<your-namespace>.svc:4000
    masterKeySecretRef:
      name: litellm-master-key
      key: LITELLM_MASTER_KEY
  EOF

3. Check the connection status:

  kubectl get litellmconnection default -n {{ .Values.watchNamespace }} -o yaml

For a full walkthrough, see:
  https://github.com/ackstorm/ach/blob/main/README.md
