<objective>
Create the new `internal/metrics/` package — a process-local Prometheus registry plus per-service typed collector factories. This is the foundational dependency for OBS-03..06: Wave 2 plans (05-04, 05-05, 05-06) will import these types to back the forwarder counter-hook stubs with real emissions and to expose `/metrics` on every Hub component.

Purpose: D-09 sets up the single source of truth for §18.5 metric label-value enums; once typed accessor methods exist, raw label strings never appear at call sites. This is the lowest-risk entry into the Phase 5 metric rollout.
Output: Reusable `internal/metrics` package + a 4th-direct `prometheus/client_golang` dependency in `go.mod` (currently indirect via controller-runtime).
</objective>
