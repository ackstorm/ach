## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| kind node ↔ host Docker daemon | The orchestrator spawns a kind cluster which uses the host's docker engine. Untrusted code inside the cluster (e.g. a malicious Plugin CR pointing at an attacker-controlled tarball) could reach the host through Docker socket misuse. Mitigation: e2e overlay does NOT mount /var/run/docker.sock into any Pod; kind's default kubelet config is unaffected; Plugin fetchers run inside the operator container with read-only rootfs. |
| operator container ↔ ach-postgres Service | The operator authenticates to Postgres via DSN-embedded credentials in the ach-db-url Secret. The dev-postgres Pod accepts any client because POSTGRES_PASSWORD=ach is the only auth gate. | e2e test runner ↔ public internet | SC1/SC4 fixtures reference external archives (github source tarballs). The kind node makes outbound network calls for these.
