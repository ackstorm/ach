## Design decisions encoded

- **D-02-v3** — stdlib `testing`, no Ginkgo. File uses `t.Run` sub-T, not `Describe`/`Ginkgo` blocks.
- **D-05-v3** — OrphanReapLive scales `deployment/ach-operator` to 0 before port-forwards, avoiding races with the in-cluster ticker. Cleanup restores `--replicas=1` and waits for rollout.
- **D-06-v3** — In-process `orphan.NewRunnable.TickOnce()` over `kubectl exec`. Audit logger writes to a `bytes.Buffer` we parse line-by-line; no `kubectl logs --since=...` race tolerance needed.
