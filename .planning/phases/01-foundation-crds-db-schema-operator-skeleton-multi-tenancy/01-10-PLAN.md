    ```
    import (
        "log/slog"
        "os"

        "github.com/ackstorm/ach/internal/config"
        "github.com/ackstorm/ach/internal/db"
    )

    func main() {
        logger := slog.New(slog.NewJSONHandler(os.Stdout, nil))

        url, err := config.MustEnvNonEmpty("ACH_DB_URL")
        if err != nil {
            logger.Error("ACH_DB_URL is required for migrate", "err", err)
            os.Exit(1)
        }
        path := config.EnvOr("ACH_MIGRATIONS_PATH", "/db/migrations")

        logger.Info("running migrations", "path", path)
        if err := db.Migrate(url, path); err != nil {
            logger.Error("migration failed", "err", err)
            os.Exit(1)
        }
        logger.Info("migrations complete")
    }
    ```

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| build context→image | `.dockerignore` controls what enters the build context. Sensitive files (`.git/`, `.planning/`) excluded. |
| base image→runtime | `gcr.io/distroless/static:nonroot` is the runtime trust base. No shell, no package manager, no setuid binaries. |
| dev compose→host | docker-compose binds Postgres/Redis to localhost ports (5432/6379). Convenient for dev; never used in prod. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-10-01 | Tampering | base image substitution at pull time | accept | `golang:1.23` and `gcr.io/distroless/static:nonroot` are well-known. Phase 7 distribution may pin to specific digests; Phase 1 uses tag names. |
| T-10-02 | Information Disclosure | `.planning/`, `cover.out`, or `.git/` leaked into a container image | mitigate | `.dockerignore` excludes all four classes. Acceptance criterion grep-asserts each entry. |
| T-10-03 | Elevation of Privilege | container runs as root | mitigate | `USER 65532:65532` (distroless nonroot UID) in every Dockerfile. Plan 08's `runAsNonRoot: true` is the second layer. |
| T-10-04 | Tampering | migration files altered between image build and Pod start | accept | Migrations are baked into the operator image (`COPY db/migrations /db/migrations`); changing them requires rebuilding the image. K8s image-pull is a separate trust boundary (out of scope for Phase 1; Phase 7 Helm chart pins to digests). |
| T-10-05 | Denial of Service | runaway Postgres data volume in local dev | accept | Named volume `postgres_data` is the developer's responsibility; `make dev-down` does not delete it. Production deployment uses K8s PVC, not docker volume. |
| T-10-06 | Spoofing | `ach-cli:test` image impersonates production CLI | accept | Phase 1 images are dev-only. Phase 7 ships signed OCI images via `ghcr.io/ackstorm/ach:<version>`. |
| T-10-07 | Tampering | CGO build slipping into the image | mitigate | Every Dockerfile sets `CGO_ENABLED=0` — statically compiled, distroless-compatible. |
| T-10-SC | Tampering | npm/pip/cargo installs | accept | No npm/pip/cargo installs. Dockerfiles use `go mod download` from `go.mod` (Plans 01/03). All Go modules are widely-deployed `[KNOWN]` packages. |
</threat_model>
