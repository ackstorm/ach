<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| K8s API server→Pod | Manifests govern what runs. CEL admission (Plan 02) handles CR shape; PodSecurityStandards (cluster-level) handles workload safety. Phase 1 manifests opt into the `restricted` PSS profile (runAsNonRoot, seccompRuntimeDefault, no privilege escalation, all caps dropped, read-only root). |
| K8s Secret→env var | Pepper + DB URL enter the Pod via `valueFrom.secretKeyRef`. Never as literal env values in the manifest. |
| init container→Postgres | The migrate-up init container holds DB DDL privileges briefly at Pod start. On failure → `Init:Error` → Pod blocks (D-08). |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-08-01 | Information Disclosure | committed placeholder pepper accidentally used in production | mitigate | Annotation `ach.ackstorm.ai/placeholder: "true"` + obvious "REPLACE-ME" placeholder text. Phase 7 Helm chart fails fast if the placeholder remains. Plan 11's e2e test asserts the Operator REFUSES to start if the pepper has the literal placeholder value (add this assertion when Plan 11 lands). |
| T-08-02 | Tampering | shared RWO PVC scheduling race during RollingUpdate | mitigate | `strategy.type: Recreate` (OP-05) forces the old Pod to terminate fully before the new one starts. Single-replica + Recreate is the canonical pattern for RWO PVCs. |
| T-08-03 | Elevation of Privilege | container escapes via privilege escalation | mitigate | Every container declares `runAsNonRoot: true`, `allowPrivilegeEscalation: false`, `capabilities.drop: [ALL]`, `readOnlyRootFilesystem: true`.
