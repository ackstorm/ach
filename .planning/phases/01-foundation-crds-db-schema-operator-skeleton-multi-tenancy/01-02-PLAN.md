|----------|-------------|
| user→K8s API server | `kubectl apply` of CRs from outside the cluster traverses kube-apiserver admission. CEL `x-kubernetes-validations` is the v1alpha1 admission boundary (CRD-03 — no `ValidatingAdmissionWebhook`). |
| K8s API server→OpenAPI schema | The CRD schema (including CEL rules) is the trust boundary that prevents malformed CRs from ever entering etcd. |
