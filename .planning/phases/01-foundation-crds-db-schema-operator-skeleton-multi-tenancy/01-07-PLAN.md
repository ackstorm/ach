    ```
    package cachefs

    import (
        "errors"
        "os"
        "path/filepath"
    )

    // ErrCacheRootMissing is returned when ACH_CACHE_ROOT does not exist or is unwritable.
    var ErrCacheRootMissing = errors.New("cachefs: ACH_CACHE_ROOT directory does not exist or is unwritable")

    // SubDirs are the five OP-10 cache directories created under the PVC mount root.
    // Order is fixed to make EnsureLayout deterministic for tests.
    var SubDirs = []string{"prompt", "plugin", "marketplace", "artifact", ".tmp"}

    // EnsureLayout creates the OP-10 cache directory tree under root.
    // Idempotent: re-running is a no-op. Returns error on root missing, permission, or ENOSPC.
    func EnsureLayout(root string) error {
        if root == "" {
            return ErrCacheRootMissing
        }
        st, err := os.Stat(root)
        if err != nil || !st.IsDir() {
            return ErrCacheRootMissing
        }
        for _, sub := range SubDirs {
            if err := os.MkdirAll(filepath.Join(root, sub), 0o755); err != nil {
                return err
            }
        }
        return nil
    }
    ```

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| operator process→PVC mount | EnsureLayout creates `0o755` directories under `root`. The caller passes `root` from `ACH_CACHE_ROOT` env var (set by the manager.yaml, sourced from the actual PVC mount path). |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-07-01 | Elevation of Privilege | path-traversal via malicious `root` | mitigate | The caller (Plan 06's operator main) sources `root` from env var `ACH_CACHE_ROOT`, defaulting to `/var/cache/ach`. K8s manifest authors (Plan 08) set this to the PVC mount path; no user-controlled input reaches `root`. Defensive: `os.Stat(root)` rejects non-directory targets. |
| T-07-02 | Tampering | `.tmp/` on a different filesystem from publish targets (`rename(2)` non-atomic) | mitigate | `EnsureLayout` creates `.tmp/` and the four publish dirs all under the SAME `root` — by construction on the same filesystem. Plan 08's manager.yaml mounts ONE PVC at the root; cross-filesystem `.tmp/` placement is structurally impossible. |
| T-07-03 | Denial of Service | ENOSPC during `MkdirAll` causes Operator crash loop | accept | Phase 1 design: Operator crash-loop on cache-init failure is correct behavior per D-13 ("Bootstrap failure aborts startup with a structured error"). K8s reschedules; operator stays in `CrashLoopBackOff` until storage is healthy. |
| T-07-04 | Information Disclosure | accidental world-readable cache contents | accept | Subdirs created with `0o755` — owner-write, group/other-read. Cached content is intentionally non-sensitive (plugin tarballs, prompt files, artifact bundles). Plaintext secrets are NEVER cached here (DB-04). |
| T-07-05 | Tampering | TOCTOU between `os.Stat` and `os.MkdirAll` | accept | Filesystem checks against the PVC mount are non-adversarial in Phase 1 — only the operator process writes here. Concurrent racers do not exist. |
| T-07-SC | Tampering | npm/pip/cargo installs | accept | No npm/pip/cargo installs. Stdlib-only Go package. |
</threat_model>
