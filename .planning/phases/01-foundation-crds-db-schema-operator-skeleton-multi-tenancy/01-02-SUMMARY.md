## Accomplishments

- **Six kinds in `api/ach/v1alpha1/`:** Environment, Plugin, PluginMarketplace, Artifact, Prompt, BackendIdentityPolicy — each with spec/status structs that mirror Hub §6/§9.3/§10/§11/§12/§13.
- **CRD-02 (Environment runtime+context):** `RuntimeBlock` and `ContextBlock` each with three optional `[]string` fields defaulting to `[]` (always-present-even-empty semantics). Resource-root CEL: `has(self.spec.runtime) && has(self.spec.context)`. `authorizedTeams` requires `MinItems=1` plus a redundant resource-root CEL `size(self.spec.authorizedTeams) >= 1`.
- **CRD-03 (source-type discriminator):** All four external-ref kinds carry an ORd-has-clauses resource-root CEL rule asserting that the subobject named after `spec.type` is present. Six per-source structs (`GitHubSource`, `GitLabSource`, `BitbucketSource`, `S3Source`, `GCSSource`, `HTTPSource`) live in `external_ref_types.go` and are referenced as `*Source` pointers in each spec.
- **CRD-03 cross-field duration:** All four external-ref kinds carry `!has(self.spec.refresh.interval) || duration(self.spec.refresh.interval) <= duration(self.spec.refresh.maxStaleness)` — admission-time guarantee that a stale-between-polls config is impossible.
- **CRD-04 (refresh.maxStaleness REQUIRED):** Each of the four external-ref kinds carries a resource-root CEL `has(self.spec.refresh.maxStaleness)` AND the `MaxStaleness` field has `+kubebuilder:validation:Required` directly on the type — defense in depth.
- **CRD-05 (Artifact.type=http ⇒ scope=object):** `artifact_types.go` carries a fourth resource-root CEL rule `self.spec.type != 'http' || self.spec.scope == 'object'`. `Scope` is enum `object|directory` with `+kubebuilder:validation:Required`.
- **CRD-08 (BackendIdentityPolicy):** `target.kind` enum `MCPServer|A2AAgent`, `target.name` DNS-1123 subdomain regex + `MaxLength=253`, `forwardIdentityJWT` `+kubebuilder:validation:Required` AND resource-root CEL `has(self.spec.forwardIdentityJWT)` — no Go zero-value default leak, no kubebuilder default annotation, both layers reject omitted-field CRs.
- **MULTI-01 (Namespaced):** Every kind carries `+kubebuilder:resource:scope=Namespaced`. Generated CRDs confirmed `scope: Namespaced` × 6, `scope: Cluster` count = 0.
- **Six generated CRD YAMLs** at `config/crd/bases/ach.ackstorm.ai_*.yaml` each carrying `x-kubernetes-validations:` entries.
- **Six valid sample CRs** at `config/samples/ach_v1alpha1_*.yaml` that pass CEL admission (Environment with empty arrays + authorized team `default`; Plugin/PluginMarketplace/Prompt with github source; Artifact with s3+directory; BackendIdentityPolicy with `forwardIdentityJWT: false`).

## Decisions Made

- **Multigroup controller path.** Kubebuilder v4 with `multigroup: true` puts controllers under `internal/controller/ach/` (group subdirectory), not `internal/controller/<kind>_controller.go` as the plan's `<files>` list literally stated. This is standard kubebuilder behavior given the Plan 01 PROJECT setup (`multigroup: true`, `group: ach`). Followed kubebuilder; tracked as a Rule 3 auto-fix because the plan's predicted path diverged from the tool's actual output (the planner's intent — "six kinds via `kubebuilder create api`" — is preserved verbatim).
- **Shared external-reference subtypes lifted to `external_ref_types.go`.** Rather than duplicating `RefreshBlock`, six per-source structs, `SourceAuthSecretRef`, and `ExternalRefStatus` across `plugin_types.go` / `pluginmarketplace_types.go` / `prompt_types.go` / `artifact_types.go`, they live once. Each spec uses pointer (`*GitHubSource`, etc.) for `+optional` semantics. Status structs embed `ExternalRefStatus` via `json:",inline"` so the OpenAPI schema stays flat (no nested `status.externalRef.*` path).
- **`MarketplaceFilters.Include/Exclude` are `[]string` at CRD admission level.** CRD-level admission only checks the field is a list-of-strings; the regex-compile gate is a Phase-2 reconcile-time check per Hub §12 (`Synced=False, reason=InvalidConfig`).
- **`HTTPSource.URL` enforces `^https://` at admission.** The Hub spec doesn't explicitly say so but Hub §10.1 wire format reads `MUST be https`. Enforcing it at CRD admission is defense in depth — the network-egress path would refuse a `http://` URL anyway, but failing fast at `kubectl apply` is better UX.
- **Artifact sample uses `type: s3` + `scope: directory`.** Chosen specifically to exercise a non-http directory case without colliding with CRD-05. The `type: http + scope: directory` invalid case is reserved for the Plan 11 envtest invalid-fixture set.
- **BackendIdentityPolicy sample sets `forwardIdentityJWT: false`.** Showcases the explicit-false form per Hub §9.3 and verifies CRD-08's REQUIRED-no-default rule (admission would reject a CR omitting the field entirely; with `false` it passes and is operationally indistinguishable from no CR).

**2. [Rule 2 — Missing Critical] Empty-array defaults on RuntimeBlock / ContextBlock list fields**
- **Found during:** Task 2 (Environment type implementation)
- **Issue:** CRD-02 requires both `runtime` and `context` blocks to always be present in the hydrate response even when one sub-field is empty. The straightforward `[]string` with `+optional` would surface as `null` (Go zero value) in JSON, not `[]`. Hub §6.4 example confirms `unresolvedRuntime.mcpServers: []` (empty list, not absent) semantics.
- **Fix:** Each RuntimeBlock / ContextBlock list field carries `+kubebuilder:default={}` so a manifest omitting a sub-field still surfaces an empty slice at the API server (kubebuilder default applies before the schema returns the CR to a reader). Same treatment applied to `UnresolvedRuntime` sub-fields.
- **Files modified:** `api/ach/v1alpha1/environment_types.go`.
- **Verification:** Generated CRD YAML at `config/crd/bases/ach.ackstorm.ai_environments.yaml` carries `default: []` on each list field within `runtime` / `context` / `unresolvedRuntime`. Sample CR explicitly lists all six sub-fields as `[]`, exercising the CRD-02 always-present-even-empty contract.
- **Committed in:** `c771d45` (Task 2 commit).

**3. [Rule 2 — Missing Critical] BackendIdentityPolicy.forwardIdentityJWT belt-and-braces required enforcement**
- **Found during:** Task 2 (BackendIdentityPolicy implementation)
- **Issue:** The plan specified the resource-root CEL `has(self.spec.forwardIdentityJWT)` for CRD-08. A bool field in Go has a zero value of `false`; the marshaller would happily serialize an omitted JSON field as the `bool` zero. The single resource-root CEL is sufficient at admission, but a missing `+kubebuilder:validation:Required` on the field itself would leak the zero value at the Go API layer (a controller calling `r.Get(ctx, ...)` then reading `policy.Spec.ForwardIdentityJWT` would see `false` for a malformed manifest that somehow bypassed admission — for example, a future webhook removal or a CEL syntax error).
- **Fix:** Added `+kubebuilder:validation:Required` to the field directly in addition to the resource-root CEL. Defense in depth: CEL rejects at admission; if CEL is ever removed/broken, the field's `Required` marker triggers OpenAPI schema validation as a second-layer fail-fast.
- **Files modified:** `api/ach/v1alpha1/backendidentitypolicy_types.go`.
- **Verification:** Generated CRD YAML carries both `required: [forwardIdentityJWT, target]` in the spec schema AND the `x-kubernetes-validations[].rule: 'has(self.spec.forwardIdentityJWT)'` entry on the resource root.
- **Committed in:** `c771d45` (Task 2 commit).

**4. [Rule 2 — Missing Critical] HTTPSource.URL https-only Pattern marker**
- **Found during:** Task 2 (external_ref_types.go HTTPSource implementation)
- **Issue:** The plan referenced Hub §10.1 (`url: MUST be https`) but did not specify a CEL or Pattern marker. Without admission enforcement, a deployer could submit a `http://` URL and the reconciler would fetch it (Phase 2). The runtime-side enforcement layer would refuse plaintext anyway (Hub: HTTPS-only via `ACH_BASE_URL`; no HTTP escape hatch), but a fail-at-admission UX is strictly better than a fail-at-reconcile-time UX.
- **Fix:** Added `+kubebuilder:validation:Pattern=^https://` to `HTTPSource.URL`. CRD admission now refuses `http://*` URLs at `kubectl apply` time.
- **Files modified:** `api/ach/v1alpha1/external_ref_types.go`.
- **Verification:** Generated CRD YAMLs (Plugin, PluginMarketplace, Prompt, Artifact) all carry `pattern: '^https://'` on `spec.http.url`.
- **Committed in:** `c771d45` (Task 2 commit).
