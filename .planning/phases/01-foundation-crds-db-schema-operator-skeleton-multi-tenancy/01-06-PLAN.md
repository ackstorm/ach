## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| env→process | Each binary reads env vars at startup. Fail-fast on missing `ACH_CREDENTIAL_HASH_PEPPER` and `ACH_DB_URL` (D-08, D-09). |
| K8s API server→operator | Namespace-scoped informer cache via `cache.Options.DefaultNamespaces` — defense in depth above RBAC. |
| network→stub | The three Hub stubs expose `/healthz` only. No request body parsing; no auth; no logging of headers. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-06-01 | Information Disclosure | pepper value logged at startup | mitigate | Acceptance criterion asserts no occurrence of `ACH_CREDENTIAL_HASH_PEPPER` in `cmd/operator/main.go` outside the `MustEnvNonEmpty` call. The value is held in a local `pepper` variable and passed nowhere logging-adjacent in Phase 1. |
| T-06-02 | Spoofing | operator watches cross-namespace CRs | mitigate | `cache.Options.DefaultNamespaces = { watchNS: {} }` confines the informer cache to a single namespace (MULTI-01). Plan 11 asserts via envtest that out-of-namespace CRs are NOT delivered. |
| T-06-03 | Denial of Service | http server in stub binaries has unbounded slowloris exposure | mitigate | `ReadHeaderTimeout: 5*time.Second` set on every stub server. (Lint rule `G112` would otherwise flag this.) |
| T-06-04 | Tampering | content-service stub exits early, failing SC #2 | mitigate | The stub's signal-handler goroutine blocks `<-sig` until SIGTERM, then graceful shutdown with 10s timeout. Acceptance criterion exercises a real `/healthz` curl. |
| T-06-05 | Elevation of Privilege | leader election in single-replica deployment causes a stale lease | accept | Leader election is OFF in Phase 1 (`--leader-elect=false` default per OP-05 single-replica Recreate). Risk surface is zero. |
| T-06-06 | Information Disclosure | `slog` JSON output includes sensitive request headers | accept | Stubs serve only `/healthz`. No request bodies, no headers read beyond the stdlib accept. Phase 4+ handlers will need redaction; Phase 1 has no such surface. |
| T-06-SC | Tampering | npm/pip/cargo installs | accept | No npm/pip/cargo installs. Go module additions only (transitive — `pgx`, `controller-runtime` from earlier plans). |
</threat_model>
