objective: |
  Establish the source-type fetcher framework consumed by the Plugin/Prompt/Artifact/PluginMarketplace reconcilers in Plans 02-05 and 02-06.

  This plan does NOT modify any controller, the operator entrypoint, or the database. It produces a self-contained `internal/sources/` package with:

  1. A uniform `Fetcher` interface (D-04, D-05) — every source type returns a streaming `io.ReadCloser` plus a `FetchResult{UpstreamRev, NotModified}` metadata record. Reconcilers own the `.tmp/<random>` lifecycle, `fsync`, and atomic `rename(2)` — fetchers stay storage-agnostic.
  2. Six per-source-type packages (`github`, `gitlab`, `bitbucket`, `s3`, `gcs`, `http`) each exporting a `*Fetcher` and a `New(...)` constructor.
  3. A package-level `errors.go` declaring sentinel errors and a `ReasonOf(err)` function that maps fetcher errors into the Hub §6.6 `SourceReachable.reason` enum — reconcilers in Plan 02-05/02-06 use `ReasonOf` instead of switching on concrete error types.
  4. A `Registry.For(spec)` lookup that consumers call once per reconcile to dispatch on `spec.Type`.

  Plug-in size cap enforcement (D-12) is the RECONCILER's responsibility, not the fetcher's — fetchers return the body raw; Plan 02-05's plugin reconciler wraps the body in `io.LimitReader(body, max+1)` and deletes the staging file on overshoot. This separation keeps the fetcher universal (size cap applies only to Plugin reconcile, not Prompt/Artifact/PluginMarketplace).

  Output: a compiling `internal/sources/` package with six fetchers wired through a registry, ready for Plan 02-05 reconcilers to consume.

The Fetcher contract this plan PRODUCES (the canonical wire between fetchers and reconcilers):

```
package sources

import (
    "context"
    "io"
    corev1 "k8s.io/api/core/v1"
)

// SourceSpec is the discriminated union the Registry uses to dispatch.
// The reconciler builds one from a Plugin/Prompt/Artifact/PluginMarketplace
// CR's spec block. Exactly one *Source subobject is non-nil per Spec.Type.
type SourceSpec struct {
    Type      string                          // "github" / "gitlab" / "bitbucket" / "s3" / "gcs" / "http"
    GitHub    *achv1alpha1.GitHubSource
    GitLab    *achv1alpha1.GitLabSource
    Bitbucket *achv1alpha1.BitbucketSource
    S3        *achv1alpha1.S3Source
    GCS       *achv1alpha1.GCSSource
    HTTP      *achv1alpha1.HTTPSource
}

// FetchRequest is what Fetcher.Fetch receives.
type FetchRequest struct {
    Spec   SourceSpec
    Secret *corev1.Secret      // resolved by the reconciler from spec.AuthSecretRef; may be nil for HTTPSource without auth
    PriorRev string             // UpstreamRev from the last successful refresh; empty on first reconcile
}

// FetchResult is what Fetcher.Fetch returns.
type FetchResult struct {
    Body        io.ReadCloser  // caller MUST close (defer body.Close())
    UpstreamRev string         // commit SHA (git) / ETag (s3 + http) / generation (gcs) / Last-Modified (http fallback)
    NotModified bool           // true when conditional GET hit (HTTP 304); Body is nil/empty in this case
}

// Fetcher is the source-type-agnostic upstream-fetch contract.
type Fetcher interface {
    Fetch(ctx context.Context, req FetchRequest) (*FetchResult, error)
}
```

The error classification table this plan PRODUCES (Hub §6.6 SourceReachable.reason enum):

| Fetcher condition | Sentinel | ReasonOf returns |
|---|---|---|
| HTTP 401 / SDK auth error | ErrUnauthorized | "Unauthorized" |
| HTTP 404 / S3 NoSuchKey / GCS storage.ErrObjectNotExist | ErrNotFound | "NotFound" |
| TCP reset / timeout / context.DeadlineExceeded / 5xx | ErrUnreachable | "Unreachable" |
| HTTP 200 but malformed body / parse failure | ErrUpstreamInvalid | "UpstreamInvalid" |
| Unknown / unwrapped | (default) | "Unreachable" (conservative — caller retries) |

ReasonOf signature: `func ReasonOf(err error) string` — uses errors.Is against the four sentinels, returns "Unreachable" by default.

```
func drainAndClose(body io.ReadCloser) {
    if body == nil { return }
    _, _ = io.Copy(io.Discard, body)
    _ = body.Close()
}
```
