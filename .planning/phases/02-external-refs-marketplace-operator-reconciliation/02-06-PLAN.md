Cross-marketplace conflict resolution (OP-08; Hub §12.3):

```
Inputs:
- mp : the PluginMarketplace being reconciled
- candidatePluginNames : []string (post-filter result)
- allMarketplaces : list of all PluginMarketplace CRs in the namespace, sorted by metadata.name
- allPluginCRs : set of metadata.name from all Plugin CRDs in the namespace

For each candidate name N:
1. If N is in allPluginCRs → DROP (Plugin CRD beats marketplace; reason "NameConflict: Plugin CRD <N> takes precedence")
2. Else look across allMarketplaces for any earlier-sorting marketplace exposing N.
   - "Earlier-sorting" = metadata.name sorts strictly before mp.metadata.name in Unicode-code-point ordering.
   - If any earlier marketplace also exposes N → DROP (reason "NameConflict: marketplace <earlier> wins")
3. Else KEEP.
```

The conflict resolution requires the reconciler to perform a List on PluginMarketplace and Plugin in the namespace each reconcile. Acceptable cost — informer-cached, sub-ms.

Status.message format for partial failures (D-10):
```
Format: "stage-2: <N> plugin(s) failed: <name1>: <reason1>, <name2>: <reason2>, ... [, +<M> more]"
- N = total failures (including the truncated ones)
- M = N - 5 (only present when N > 5)
- Each <reason> is a short string derived from sources.ReasonOf(err) or a §12.4 mnemonic (e.g. "UnsupportedPluginSource" for npm)
- The string is bounded ~500 chars typical, far under Kubernetes' status.message size limit (4096 chars)
```

    // ConflictDecision is the per-plugin outcome of the cross-marketplace
    // name-conflict resolution per OP-08 / Hub §12.3.
    type ConflictDecision struct {
        PluginName string
        Kept       bool   // true = this marketplace materializes this plugin name
        Reason     string // empty when Kept=true; populated with NameConflict reason when Kept=false
    }

    // resolveConflicts decides which of myCandidates this marketplace
    // (myMarketplace) is permitted to materialize, given:
    //   - allMarketplaces: every PluginMarketplace CR in the namespace
    //     (the candidate's set is the union of post-filter results across these)
    //   - allPluginCRs: every Plugin CRD metadata.name in the namespace
    //
    // Rules (deterministic, Unicode-code-point sort):
    //  1. If pluginName is in allPluginCRs → Kept=false, Reason="Plugin CRD <name> takes precedence"
    //  2. Else find the alphabetically-lowest marketplace.metadata.name
    //     among {m | m's filter result contains pluginName}.
    //     If that lowest is THIS marketplace → Kept=true.
    //     Else → Kept=false, Reason="marketplace <winner> takes precedence"
    //
    // To compute (2), the caller passes a marketplace→[]pluginName map so
    // resolveConflicts doesn't re-parse / re-filter every marketplace per
    // candidate. The map is built once per reconcile by the caller (Stage-1.5
    // result for THIS marketplace plus the post-filter result of every OTHER
    // marketplace cached from their last reconcile — pragmatic: read from
    // marketplace_plugins DB rows for the other marketplaces).
    //
    // For Phase 2 a simpler approach is acceptable: pass the live List of
    // marketplaces and re-parse+filter each one on every reconcile. The map
    // optimization is a v1beta1 concern.
    func resolveConflicts(
        myMarketplaceName string,
        myCandidates []ClaudeCodeMarketplacePlugin,
        otherMarketplaceCatalogs map[string][]string,  // marketplace name -> plugin name list (post-filter)
        allPluginCRs map[string]struct{},               // set of Plugin CRD metadata.names
    ) []ConflictDecision

    // listPluginCRNames returns the set of every Plugin CR's metadata.name in
    // the namespace via the informer cache.
    func listPluginCRNames(ctx context.Context, c client.Client, namespace string) (map[string]struct{}, error) {
        var plugins achv1alpha1.PluginList
        if err := c.List(ctx, &plugins, client.InNamespace(namespace)); err != nil {
            return nil, err
        }
        out := make(map[string]struct{}, len(plugins.Items))
        for _, p := range plugins.Items {
            out[p.Name] = struct{}{}
        }
        return out, nil
    }

    // listOtherMarketplaceCatalogs returns a map[marketplaceName][]pluginName for every
    // PluginMarketplace CR in the namespace EXCEPT self, drawn from marketplace_plugins
    // DB rows (the prior reconcile's published state). When DB is nil, returns an empty map
    // (treats every candidate as winner — degraded mode for unit tests).
    func listOtherMarketplaceCatalogs(ctx context.Context, c client.Client, dbPool *pgxpool.Pool, namespace, selfName string) (map[string][]string, error) {
        var mps achv1alpha1.PluginMarketplaceList
        if err := c.List(ctx, &mps, client.InNamespace(namespace)); err != nil {
            return nil, err
        }
        out := make(map[string][]string)
        if dbPool == nil { return out, nil }
        for _, mp := range mps.Items {
            if mp.Name == selfName { continue }
            rows, err := db.ListMarketplacePlugins(ctx, dbPool, mp.Name)
            if err != nil { continue }  // best-effort; missing entries don't block reconcile
            names := make([]string, 0, len(rows))
            for _, r := range rows { names = append(names, r.Name) }
            out[mp.Name] = names
        }
        return out, nil
    }
