    `func IsEmpty(root string) (bool, error)`:
    1. Validate via os.Stat: missing → ErrCacheRootMissing; not-a-dir → ErrCacheRootMissing.
    2. Read root entries: `entries, err := os.ReadDir(root)`.
    3. For each entry: if name == ".tmp", continue (the .tmp staging dir's presence does not count against emptiness — it's part of the layout, not user data); otherwise descend into the subdir: `sub, err := os.ReadDir(filepath.Join(root, entry.Name()))`. If sub is non-empty (len > 0), return (false, nil). On ReadDir error inside the subdir, treat as "populated" defensively (return false, nil; do NOT propagate the error — the operator is about to make a "fresh cache" decision based on this, and erring on the side of "not empty" preserves any data the reconcilers might have written and we can't read).
    4. If every non-.tmp subdir is missing or empty, return (true, nil).

    Edge cases documented in code comment:
    - root contains only the .tmp/ directory with files inside → return (true, nil). The .tmp/ staging dir is operator-internal; orphan files there are not "user data" and SweepTmp handles them.
    - root contains a stray file (not a subdir) at the top level → currently counted as "populated" since the loop's `sub, err := os.ReadDir` would fail with ENOTDIR; per step 3's defensive rule, return (false, nil). Stray top-level files shouldn't exist under EnsureLayout's invariants anyway.

    `func SweepTmp(root string, maxAge time.Duration) error`:
    1. tmp := filepath.Join(root, ".tmp")
    2. `entries, err := os.ReadDir(tmp)`. If errors.Is(err, fs.ErrNotExist), return nil (no .tmp/ to sweep — benign; the caller is the operator's hourly Runnable, not the bootstrap path).
    3. cutoff := time.Now().Add(-maxAge)
    4. For each entry:
       - info, err := entry.Info(). On err (file disappeared mid-iteration → ErrNotExist), continue silently.
       - If info.ModTime().Before(cutoff): `_ = os.Remove(filepath.Join(tmp, entry.Name()))` — ignore Remove error (concurrent rename mid-sweep is the only realistic failure; the file is already at its production location).
    5. Return nil unconditionally. SweepTmp is best-effort; partial failures don't propagate.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| ACH audit records ↔ Kubernetes log collection (fluent-bit / Loki) | The audit logger writes JSON lines to os.Stdout. Anything the caller passes into the slog.Logger.Info call becomes plaintext on the log shipper bus. Caller hygiene (no plaintext keys, no body content) is the only protection. |
| .tmp/ filesystem entries ↔ live reconciler rename(2) | SweepTmp's os.Remove races with reconciler rename(2) calls; both must be idempotent / mutually tolerant. The reconciler writes under os.CreateTemp's random suffix so two concurrent reconciles never collide on the same .tmp/ filename. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-04-01 | Information disclosure | audit logger emitting plaintext credential value because caller passed it as an attribute | accept | The handler is intentionally raw per D-17 + [feedback_litellm_operator_no_redaction_filter]. Discipline is enforced AT CALL SITES — Plan 02-08 orphan-cleanup tasks specify the exact attributes (target.kind, target.name, outcome) and explicitly forbid passing credential plaintext. Phase 3 will continue the discipline for pk_/ek_ events. A future linter or grep gate could check "audit.NewLogger().Info" calls for forbidden attribute names. |
| T-02-04-02 | Information disclosure | audit JSON line wrapping past 1 KiB and getting truncated by the log shipper | accept | Production attribute payloads are small (3-5 keys, all short strings). Phase 2 events fit in <300 bytes per line. |
| T-02-04-03 | Tampering | SweepTmp deleting a freshly-created staging file mid-reconcile | mitigate | The reconciler's os.CreateTemp gives every staging file a cryptographically-random suffix; SweepTmp's ModTime-based predicate requires the file be older than maxAge (production: 1h). A reconcile that takes >1h to complete its single rename(2) is anomalous; even if it does, os.Remove failing because the rename already moved the file is a benign no-op SweepTmp ignores. |
| T-02-04-04 | Denial of service | IsEmpty triggering ResetExternalRefRefreshOnEmptyCache on every pod restart, causing thundering-herd refresh across hundreds of CRs | accept | OP-11 explicitly intends this: empty cache + non-NULL refresh timestamps is a data-loss scenario; thundering-herd refresh is the correct recovery. Controller-runtime workqueue rate limiting bounds the actual upstream call rate. v1beta1 may add a Backoff knob. |
| T-02-04-05 | Tampering | A non-.tmp top-level entry under cacheRoot (e.g. a "lost+found" from fsck) confusing IsEmpty's predicate | mitigate | IsEmpty defensively treats any non-.tmp entry that ReadDir succeeds on as "populated"; this errs toward NOT triggering the reset. Acceptance: TestIsEmpty_OnePluginFile asserts the predicate. |
</threat_model>
