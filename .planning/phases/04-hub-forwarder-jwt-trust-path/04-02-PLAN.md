Three concerns, one package — they share the `signerSlot` type and the `Ed25519Signer` is the consumer of both the loader (writes) and the JWKS handler (reads).

- FWD-07 — sign JWTs with EdDSA/Ed25519, 120-second exp, no jti, claims {iss, sub, aud, iat, exp}.

- FWD-09 — manual rotation via `current` + optional `next` slot in a single K8s Secret; ≥24h overlap; refuse-to-start on missing/malformed current slot.

Method `func (l *SecretLoader) LoadOnce(secret *corev1.Secret) error` — process-start path. Refuses to load on missing/malformed current slot:
- curKid := string(secret.Data[DataKeyCurrentKid])
- curSeed := secret.Data[DataKeyCurrentSeed]
- curSlot, err := newSignerSlot(curKid, curSeed); if err != nil → return fmt.Errorf("jwt secret %s/%s current: %w", l.namespace, l.name, err)
- l.signer.LoadCurrent(curSlot)
- if nxtKid := string(secret.Data[DataKeyNextKid]); nxtKid != "" {
    nxtSlot, err := newSignerSlot(nxtKid, secret.Data[DataKeyNextSeed])
    if err != nil { l.log.Error(err, "next slot malformed; continuing with current only"); l.signer.LoadNext(nil); return nil }
    l.signer.LoadNext(nxtSlot)
  } else { l.signer.LoadNext(nil) }
- l.log.Info("jwt signing keys loaded", "current.kid", curKid, "next.present", l.signer.next.Load() != nil)
- return nil

Method `func (l *SecretLoader) Reload(secret *corev1.Secret) error` — informer event path. Refuses to UPDATE on malformed current slot (KEEPS prior slot; logs error). On success: identical to LoadOnce.
- curKid := string(secret.Data[DataKeyCurrentKid])
- curSeed := secret.Data[DataKeyCurrentSeed]
- curSlot, err := newSignerSlot(curKid, curSeed); if err != nil { l.log.Error(err, "jwt secret reload current malformed; keeping prior slot"); return err }
- l.signer.LoadCurrent(curSlot)
- next slot handling identical to LoadOnce.
- l.log.Info("jwt signing keys reloaded", "current.kid", curKid)
- return nil

Compile-time clarification comment: LoadOnce is intended for the single startup call (caller surfaces error to the cobra RunE for refuse-to-start). Reload is intended for the controller-runtime informer event handler (caller logs but does not crash).

```
type jwksDoc struct { Keys []JWK `json:"keys"` }

// JWKSHandler returns an http.HandlerFunc that publishes signer.JWKS() as
// application/jwk-set+json per FWD-08 / Hub §9.2. Cache-Control set to
// "public, max-age=3600" (the 1-hour TTL that makes ≥24h rotation overlap
// necessary per FWD-09).
func JWKSHandler(signer Signer) http.HandlerFunc {
    return func(w http.ResponseWriter, r *http.Request) {
        out := jwksDoc{Keys: signer.JWKS()}
        if out.Keys == nil { out.Keys = []JWK{} } // ensure non-nil for "keys":[]
        w.Header().Set("Content-Type", "application/jwk-set+json")
        w.Header().Set("Cache-Control", "public, max-age=3600")
        w.WriteHeader(http.StatusOK)
        _ = json.NewEncoder(w).Encode(out)
    }
}
```
