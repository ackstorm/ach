<objective>
Phase 4 Wave 2 forwarding plane: the `httputil.ReverseProxy` + four per-route handlers that glue Plans 04-01 (headers), 04-02 (jwt), 04-04 (bip), 04-06 (precheck) into the request flow. This is where FWD-01..06 actually become observable HTTP behavior.

Per FWD-01 + D-05: ONE `*httputil.ReverseProxy` shared by all four routes. Director rewrites scheme+host+headers; ModifyResponse is a no-op pass-through (LiteLLM's status/headers/body flow back verbatim).

Per FWD-05 + D-13: JWT minted ONLY on /mcp/{name} + /a2a/{name} AND ONLY when BIP resolver returns a winner with ForwardIdentityJWT=true. JWT attaches via `req.Header.Set("Authorization", "Bearer "+token)` AFTER headers.StripAndRewrite has cleared any incoming Authorization (Director runs strip pass; per-route handler attaches JWT BEFORE calling rp.ServeHTTP — this ordering works because handler mutates req.Header, Director receives the same Request, strip pass already ran in Director before handler... no, order matters).

Per FWD-06 (v1alpha1 scope): Environment attribution tag injection is REQUEST BODY mutation, scoped to `/v1` and `/gemini` (LiteLLM chat-completion JSON envelope honors `metadata.tags`). The per-route handler calls `InjectEnvironmentTag` BEFORE `rp.ServeHTTP` for `ek_` traffic only. Body mutation is safe for SSE preservation because SSE is RESPONSE-side; the REQUEST body for chat completions is always buffered JSON (even when `"stream": true` appears in the body — that flag governs the response). `/mcp` and `/a2a` request-body tagging is DEFERRED to v1beta1 — those routes don't carry a chat-completion JSON envelope, and Hub spec §6.3 says "route-specific equivalents" without naming them. CONTEXT.md `<deferred>` and ROADMAP SC#2 are updated by this plan's revision; no MCP/A2A body or header tagging ships in v1alpha1.

CRITICAL ORDERING (per PATTERNS.md "All header strip+rewrite happens INSIDE Director — except the Authorization: Bearer <JWT> write, which happens in the per-route handler BEFORE rp.ServeHTTP"):

1. Per-route handler runs precheck.
2. Per-route handler runs bip.ResolveWinner (only on /mcp + /a2a).
3. Per-route handler MINTS JWT but does NOT write Authorization to req.Header yet.
4. Per-route handler stores JWT in a request-context value via `r = r.WithContext(context.WithValue(r.Context(), jwtCtxKey, token))`.
5. For HandlerV1 + HandlerGemini, if `kc.KeyType == "ek"`, call `InjectEnvironmentTag(r, kc.Environment)` (ignore error — fail-open).
6. Per-route handler calls `rp.ServeHTTP(w, r)`.
7. Director runs: extracts token from context, calls headers.StripAndRewrite, THEN if token present sets `req.Header.Set("Authorization", "Bearer "+token)`. This ordering means headers.StripAndRewrite's Authorization-strip runs FIRST, then the JWT write is the very last header touch — no race window where Director clears the JWT.

Output: 3 new Go files (proxy.go for Director/ErrorHandler, handlers.go for the four route wrappers, tags.go for FWD-06 body injection) + tests using httptest.Server + table-driven scenarios.

// ctxKey is the unexported type used for context keys in this package
// (prevents collisions with foreign packages' context values).
type ctxKey int

const (
    // jwtCtxKey holds the per-request ACH JWT string when a BIP winner
    // opts in on /mcp/{name} or /a2a/{name}. Director reads + writes it
    // to req.Header AFTER headers.StripAndRewrite.
    jwtCtxKey ctxKey = iota + 1
)

// WithJWT stores a minted JWT in the request context for Director to attach.
// Per-route handlers call this BEFORE invoking ReverseProxy.ServeHTTP.
func WithJWT(ctx context.Context, token string) context.Context {
    return context.WithValue(ctx, jwtCtxKey, token)
}

func jwtFromCtx(ctx context.Context) (string, bool) {
    token, ok := ctx.Value(jwtCtxKey).(string)
    return token, ok && token != ""
}

// Deps wires the proxy's static configuration.
type Deps struct {
    LiteLLMUpstream  *url.URL
    LiteLLMSharedKey string
    Logger           *slog.Logger
}

// New constructs the shared *httputil.ReverseProxy. One instance per
// process; all four routes (/v1, /gemini, /mcp, /a2a) share it.
func New(deps Deps) *httputil.ReverseProxy {
    return &httputil.ReverseProxy{
        Director: func(req *http.Request) {
            // 1. Rewrite scheme + host (D-05 step 1).
            req.URL.Scheme = deps.LiteLLMUpstream.Scheme
            req.URL.Host   = deps.LiteLLMUpstream.Host
            req.Host       = "" // let Go set Host header from URL.Host (D-05; avoid sending client's Host upstream)
            // 2. req.URL.Path preserved verbatim (D-05 step 2).
            // 3. Extract KeyContext for x-litellm-key-id source.
            litellmToken := ""
            if kc, ok := middleware.KeyContextFromCtx(req.Context()); ok {
                litellmToken = kc.LitellmToken
            }
            // 4. Strip + rewrite (D-06, D-07).
            headers.StripAndRewrite(req.Header, deps.LiteLLMSharedKey, litellmToken)
            // 5. JWT attach LAST — strip already cleared client Authorization (D-05 step 4).
            if token, present := jwtFromCtx(req.Context()); present {
                req.Header.Set("Authorization", "Bearer "+token)
            }
        },
        ModifyResponse: nil, // pass-through (D-05)
        ErrorHandler: func(w http.ResponseWriter, r *http.Request, err error) {
            // Never echo the raw err string — it may contain internal
            // hostnames or upstream metadata. Map to upstream_unreachable
            // and log the err on the server side.
            deps.Logger.Error("forwarder upstream error",
                slog.String("path", r.URL.Path),
                slog.String("err", err.Error()))
            metrics.IncRequests(routeFor(r.URL.Path), keyTypeFor(r.Context()), "upstream_unreachable")
            metrics.IncLiteLLMUnreachable()
            render.Error(w, http.StatusBadGateway, "upstream_unreachable",
                "upstream connection error",
                middleware.RequestIDFromCtx(r.Context()))
        },
    }
}

// routeFor extracts the top-level route name for metrics labels.
// "/v1/chat/completions" → "/v1"; "/mcp/foo/bar" → "/mcp"; etc.
func routeFor(path string) string {
    switch {
    case strings.HasPrefix(path, "/v1"): return "/v1"
    case strings.HasPrefix(path, "/gemini"): return "/gemini"
    case strings.HasPrefix(path, "/mcp"): return "/mcp"
    case strings.HasPrefix(path, "/a2a"): return "/a2a"
    }
    return "unknown"
}

// keyTypeFor extracts pk/ek/none from the request context KeyContext.
func keyTypeFor(ctx context.Context) string {
    if kc, ok := middleware.KeyContextFromCtx(ctx); ok {
        return kc.KeyType
    }
    return "none"
}

type precheckFunc func(ctx context.Context, kc middleware.KeyContext, name string, deps precheck.Deps) error

func handlerNamed(deps HandlerDeps, kind string, check precheckFunc, audPrefix, routeLabel string) http.HandlerFunc {
    rp := New(deps.Deps)
    return func(w http.ResponseWriter, r *http.Request) {
        kc, _ := middleware.KeyContextFromCtx(r.Context())
        name := chi.URLParam(r, "name")
        reqID := middleware.RequestIDFromCtx(r.Context())

        // 1. Precheck — §5.1 step-4.
        if err := check(r.Context(), kc, name, deps.PrecheckDeps); err != nil {
            outcome, status, code := classifyPrecheckErr(err)
            metrics.IncRequests(routeLabel, kc.KeyType, outcome)
            if errors.Is(err, precheck.ErrLiteLLMUnreachable) { metrics.IncLiteLLMUnreachable() }
            render.Error(w, status, code, codeMessage(code), reqID)
            return
        }

        // 2. BIP resolve.
        winner := bip.ResolveWinner(r.Context(), deps.PrecheckDeps.K8sClient, kind, name, deps.Namespace)
        if winner == nil {
            metrics.IncJWTSuppressed(kind, "no_policy") // includes explicit opt-out (D-Discretion)
            metrics.IncRequests(routeLabel, kc.KeyType, "forwarded")
            rp.ServeHTTP(w, r)
            return
        }

        // 3. Sign + stash for Director.
        token, err := deps.Signer.Sign(r.Context(), jwt.Claims{
            Iss: deps.BaseURL,
            Sub: deps.Namespace + "/" + kc.OwnerEmail,
            Aud: audPrefix + name,
        })
        if err != nil {
            metrics.IncJWTSuppressed(kind, "signing_failure")
            metrics.IncRequests(routeLabel, kc.KeyType, "internal_error")
            render.Error(w, http.StatusInternalServerError, "internal_error", "jwt sign failed", reqID)
            return
        }
        metrics.IncJWTSigned(kind)
        metrics.IncRequests(routeLabel, kc.KeyType, "forwarded")

        // 4. Hand off — Director reads jwtCtxKey and writes the
        //    Authorization header AFTER headers.StripAndRewrite.
        r = r.WithContext(WithJWT(r.Context(), token))
        rp.ServeHTTP(w, r)
    }
}

// classifyPrecheckErr maps typed sentinels to outcome + HTTP status + envelope code.
func classifyPrecheckErr(err error) (outcome string, status int, code string) {
    switch {
    case errors.Is(err, precheck.ErrUnauthorizedResource):
        return "unauthorized_resource", http.StatusForbidden, "unauthorized_resource"
    case errors.Is(err, precheck.ErrUnauthorizedTeam):
        return "unauthorized_team", http.StatusForbidden, "unauthorized_team"
    case errors.Is(err, precheck.ErrLiteLLMUnreachable):
        return "litellm_unreachable", http.StatusServiceUnavailable, "litellm_unreachable"
    case errors.Is(err, precheck.ErrInvalidKeyType):
        return "invalid_key_type", http.StatusUnauthorized, "invalid_key_type"
    case errors.Is(err, precheck.ErrEnvironmentNotFound):
        return "environment_not_found", http.StatusNotFound, "environment_not_found"
    }
    return "internal_error", http.StatusInternalServerError, "internal_error"
}

func codeMessage(code string) string {
    // Stable human-readable messages per outcome. Production code may
    // localize; v1alpha1 ships English literals matching the Hub §15.5
    // outcome enum.
    switch code {
    case "unauthorized_resource": return "name not authorized for bound environment"
    case "unauthorized_team":     return "caller's teams do not grant access to this resource"
    case "litellm_unreachable":   return "litellm reachability failure during teams resolve"
    case "invalid_key_type":      return "invalid or missing key type for this route"
    case "environment_not_found": return "environment not found"
    case "internal_error":        return "internal error"
    }
    return ""
}

const (
    // tagPrefix is the FWD-06 tag namespace. All Environment attribution
    // tags ship as "environment:<name>". Greppable, parseable upstream by
    // LiteLLM's tag aggregation per Hub §6.3.
    tagPrefix = "environment:"

    // maxBodyForTagInjection caps request body size for tag injection.
    // Mirrors http.Server.MaxHeaderBytes (1 MiB) per D-04 spirit; FWD-06
    // is not expected to carry large bodies (chat completions are small).
    // Larger bodies fail-open with no tag — observability is best-effort.
    maxBodyForTagInjection = 1 << 20 // 1 MiB
)

// errBodyTooLarge / errNotJSON / errEmptyEnvironment are internal sentinels
// for tests; callers should ignore the error (fail-open policy per FWD-06).
var (
    errBodyTooLarge     = errors.New("request body exceeds tag-injection cap")
    errNotJSON          = errors.New("request Content-Type is not application/json")
    errEmptyEnvironment = errors.New("environmentName is empty")
)

// InjectEnvironmentTag mutates req.Body in place to add
// "environment:<environmentName>" to metadata.tags[] in the JSON request
// body, per FWD-06 (Hub §5.1, §6.3). Returns a non-nil error on failure
// but the caller is EXPECTED to ignore it — tagging is observability, not
// security; spec §6.3 is silent on error semantics so we fail-open to
// avoid blocking legitimate traffic on a tagging hiccup.
//
// Safe to call alongside SSE: SSE is RESPONSE-side; request body for
// LiteLLM chat completions is always buffered JSON, even when the body
// contains "stream": true (that flag controls the response).
//
// Scope (v1alpha1): /v1 + /gemini per-route handlers only.
// MCP/A2A tag injection deferred to v1beta1.
func InjectEnvironmentTag(req *http.Request, environmentName string) error {
    if environmentName == "" {
        return errEmptyEnvironment
    }
    if req == nil || req.Body == nil || req.Body == http.NoBody {
        return nil
    }
    ct := req.Header.Get("Content-Type")
    // Strict prefix match — accept "application/json" or "application/json; charset=utf-8".
    // Reject multipart, form-encoded, octet-stream, missing header.
    if !strings.HasPrefix(strings.ToLower(strings.TrimSpace(ct)), "application/json") {
        return errNotJSON
    }
    // Reject early on Content-Length cap (avoid reading megabytes).
    if req.ContentLength > maxBodyForTagInjection {
        return errBodyTooLarge
    }
    // Defensive read with a hard cap (Content-Length may be -1 or wrong).
    limited := io.LimitReader(req.Body, maxBodyForTagInjection+1)
    raw, readErr := io.ReadAll(limited)
    _ = req.Body.Close()
    if readErr != nil {
        // Restore the body to what we read so the downstream proxy can
        // still attempt to forward; if the read was partial, the upstream
        // will see a truncated body and reject — same as if tagging hadn't
        // been attempted. Don't pretend the body is intact.
        req.Body = io.NopCloser(bytes.NewReader(raw))
        return readErr
    }
    if len(raw) > maxBodyForTagInjection {
        req.Body = io.NopCloser(bytes.NewReader(raw))
        return errBodyTooLarge
    }

    // Parse into a generic map so we don't impose a schema on LiteLLM
    // request bodies (which evolve independently per provider).
    var doc map[string]any
    if err := json.Unmarshal(raw, &doc); err != nil {
        req.Body = io.NopCloser(bytes.NewReader(raw))
        return err
    }

    // Ensure metadata is an object.
    metaRaw, metaPresent := doc["metadata"]
    var meta map[string]any
    if metaPresent {
        var ok bool
        meta, ok = metaRaw.(map[string]any)
        if !ok {
            // metadata exists but is not an object — fail-open, leave body unchanged.
            req.Body = io.NopCloser(bytes.NewReader(raw))
            return errors.New("metadata is not a JSON object")
        }
    } else {
        meta = map[string]any{}
    }

    // Ensure metadata.tags is an array.
    tagsRaw, tagsPresent := meta["tags"]
    var tags []any
    if tagsPresent {
        var ok bool
        tags, ok = tagsRaw.([]any)
        if !ok {
            req.Body = io.NopCloser(bytes.NewReader(raw))
            return errors.New("metadata.tags is not a JSON array")
        }
    } else {
        tags = []any{}
    }

    // Append (no dedupe — see TG12).
    tags = append(tags, tagPrefix+environmentName)
    meta["tags"] = tags
    doc["metadata"] = meta

    // Re-serialize.
    out, err := json.Marshal(doc)
    if err != nil {
        req.Body = io.NopCloser(bytes.NewReader(raw))
        return err
    }

    req.Body = io.NopCloser(bytes.NewReader(out))
    req.ContentLength = int64(len(out))
    req.Header.Set("Content-Length", strconv.Itoa(len(out)))
    return nil
}
