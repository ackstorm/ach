<objective>
Phase 4 Wave 1 leaf package: implement the D-06/D-07 header strip-and-rewrite contract as a pure function, and stand up the metrics counter-hook stubs that every downstream forwarder file calls (no-op bodies; Phase 5 OBS-03..06 replaces).

Purpose: FWD-04 mandates that EVERY route strips the named header families and writes exactly two LiteLLM headers. Centralizing this as a pure function makes the test surface exhaustive (case-insensitive prefix matches, Connection-named tokens, hop-by-hop edge cases) and lets the Director (Plan 04-07) stay a 5-liner.

FWD-11 (no plaintext key in access logs) is enforced by the AccessLog middleware Plan 04-08 wires; this plan ships the redaction-friendly headers stripped, but the AccessLog redaction itself lives in `internal/platformapi/middleware` which is already on disk and reused verbatim.

FWD-06 (Environment attribution tag for `ek_` traffic) is REQUEST-BODY mutation, not header work — it lives in Plan 04-07's new `internal/forwarder/proxy/tags.go` (Task 3). This plan no longer claims FWD-06 because the strip+rewrite pure function does not — and structurally cannot — touch `req.Body`.

Output: 2 new packages, both stdlib-only (no go.mod entries).
</objective>

Create `internal/forwarder/headers/strip.go` exporting one function and three package-level constants:

```
package headers

const (
    prefixXLiteLLM = "x-litellm-"
    prefixXAch     = "x-ach-"
)

var hopByHop = []string{
    "Connection", "Keep-Alive", "Proxy-Authenticate", "Proxy-Authorization",
    "TE", "Trailer", "Transfer-Encoding", "Upgrade",
}

func StripAndRewrite(h http.Header, sharedKey, litellmToken string)
```

Implementation contract (per D-06 + D-07; per FWD-04):

1. Read incoming Connection token list FIRST into a `connNamed []string`: iterate `h.Values("Connection")`, split each entry on `,`, `strings.TrimSpace` each token, skip empty tokens. Use `textproto.CanonicalMIMEHeaderKey(token)` to normalize each token to canonical form for the strip pass.
2. Strip pass — iterate `for k := range h`:
   - Drop `Authorization` (canonical form).
   - Drop any key whose `strings.ToLower(k)` has prefix `prefixXLiteLLM` or `prefixXAch`.
   - Drop any key whose canonical form is in `hopByHop`.
   - Drop any key whose canonical form is in `connNamed`.
   - Use `delete(h, k)` (safe to delete inside the iteration; `http.Header` is `map[string][]string`).
3. Write pass — `h.Set("x-litellm-api-key", sharedKey)` + `h.Set("x-litellm-key-id", litellmToken)`. `h.Set` automatically canonicalizes to `X-Litellm-Api-Key` / `X-Litellm-Key-Id`.

NEVER call `h.Set("Authorization", ...)`. The JWT-attach for /mcp + /a2a happens OUTSIDE Director (per D-Discretion "Per-route handler split"); this function is the GENERIC pre-proxy transform and does NOT write Authorization.

Use `imports`: `net/http`, `net/textproto`, `strings`. Stdlib only.
