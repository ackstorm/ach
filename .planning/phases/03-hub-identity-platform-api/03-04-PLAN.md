## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| crypto/rand kernel boundary | Random bytes flow from kernel CSPRNG into ACH process memory; rand.Read failure is process-fatal (Go convention) |
| keys package -> caller | Bearer plaintext crosses package boundary; caller is responsible for "exactly once" emission |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-04-01 | Information Disclosure | bearer plaintext logged | mitigate | Package has zero log/slog/fmt imports (verified by acceptance criteria grep gate). Any future commit that adds a log call breaks the discipline doc + must fail code review |
| T-03-04-02 | Information Disclosure | predictable bearer plaintext | mitigate | crypto/rand only; 16 bytes = 130 bits of entropy; far above the birthday bound for any realistic key space. T-KEY-03 alignment |
| T-03-04-03 | Tampering | timing attack on bearer compare | mitigate | ConstantTimeEqual uses `crypto/subtle.ConstantTimeCompare`. Length-mismatch early-return is not a leak (length is not secret). T-KEY-02 alignment |
| T-03-04-04 | Tampering | bearer plaintext format collision | mitigate | strict 26-char base32-lower suffix + literal `pk_`/`ek_` prefix; ClassifyBearer rejects shorter/longer/wrong-case inputs. Defeats injection of `pkid_*` strings into bearer fields |
| T-03-04-05 | Repudiation | ULID timestamp predictability | accept | ULID embeds wall-clock ms in the high bits; this leaks creation time but NOT identity. Acceptable per Hub §16 (key_id is "opaque" but not "unpredictable" — opaque means consumers don't parse the structure) |
| T-03-04-SC | Tampering | npm/pip/cargo installs | mitigate | One new go.mod entry: `github.com/oklog/ulid/v2`. Legitimacy verified in Task 1 (MIT, ~3.4k stars, k8s ecosystem usage). NOT `[SLOP]`; mark `[VERIFIED]` |
