1. **SC#1 — SSO success path:** First-time SSO creates LiteLLM user, adds to `default` Team, returns `pk_` plaintext exactly once. Missing `default` Team yields `500 default_team_missing` with audit `outcome=default_team_missing`. ACH never sets default `max_budget`.

2. **SC#2 — Hydrate contract:** `POST /platform/hydrate` accepts both `pk_` and `ek_` per §15.1. `pk_` requires body `environment` (else `400 missing_environment`). `ek_` makes it optional (mismatch → `403 wrong_environment`). Response: `schemaVersion: "v1alpha1"`, runtime + context always present (`[]` when empty), never `pk_`/`ek_` plaintext.

3. **SC#3 — env-keys §8.2 8-step:** `POST /platform/env-keys` verifies Environment non-terminating (else `404 environment_not_found`), waits for `AccessGroupSynced=True` (else `503 not_ready`), idempotent verify-or-create LiteLLM user, create-then-insert with rollback. Returns `key_id=ekid_…` + `plaintext` exactly once.

4. **SC#4 — Asymmetric revocation:** `pk_` via `/platform/admin/keys/revoke` → Postgres flip FIRST then LiteLLM then Redis (DB is visible barrier). `ek_` revoke calls LiteLLM FIRST then DB flip then Redis (LiteLLM is runtime barrier). `DELETE /platform/env-keys/{key_id}` returns 204 only after LiteLLM ack.

5. **SC#5 — Admin gate:** Admin endpoints reject any `ek_` with `401 invalid_key_type`; non-allowlisted callers get `403 not_admin` BEFORE any other validation; allowlist read at process start from `/etc/ach/admins/admins.txt`; `/platform/admin/refresh` patches `ach.ackstorm.ai/force-refresh` annotation and returns `202 Accepted`.

6. **SC#6 — Audit invariant:** Every `pk_`/`ek_` create+revoke, every Environment lifecycle event, every hydrate, every admin op emits structured JSON audit event with `actor=<namespace>/<sso-email>`, `outcome` from §18.2 enum, `request_id`, and `key.id` in `pkid_`/`ekid_` form. Sliding-window `pk_` extension is NOT its own event.

**Audit invariant assertion shape (OBS-02 — primary REQ for this plan):**

```go
type AuditRecord struct {
    Timestamp string `json:"timestamp"`  // RFC 3339 UTC
    Audit     bool   `json:"audit"`      // always true
    Action    string `json:"action"`     // matches audit.Action* constants
    Outcome   string `json:"outcome"`    // matches audit.Outcome* enum
    Actor     string `json:"actor"`      // "<namespace>/<email>"
    RequestID string `json:"request_id"` // "req_<ulid>"
    KeyID     string `json:"key.id"`     // "pkid_..." or "ekid_..." or absent
    TargetKind string `json:"target.kind,omitempty"`
    TargetName string `json:"target.name,omitempty"`
    // ... extra fields per audit.Event.Extra
}

func assertAuditRecord(t *testing.T, line []byte) {
    var rec AuditRecord
    require.NoError(t, json.Unmarshal(line, &rec))
    require.True(t, rec.Audit)
    require.NotEmpty(t, rec.Timestamp)
    require.NotEmpty(t, rec.Actor)
    require.Contains(t, rec.Actor, "/")  // namespace/email format
    require.NotEmpty(t, rec.Action)
    require.NotEmpty(t, rec.Outcome)
    require.NotEmpty(t, rec.RequestID)
    require.True(t, strings.HasPrefix(rec.RequestID, "req_"))
    if rec.KeyID != "" {
        require.True(t,
            strings.HasPrefix(rec.KeyID, "pkid_") || strings.HasPrefix(rec.KeyID, "ekid_"),
            "key.id must use pkid_/ekid_ form, got: %s", rec.KeyID)
    }
    // No-plaintext invariant: search raw line for pk_xxx / ek_xxx patterns OUTSIDE the key.id field.
    rawLine := string(line)
    require.False(t, regexp.MustCompile(`"(?:[^"]*?)":\s*"pk_[a-z2-7]{26}"`).MatchString(rawLine),
        "pk_ plaintext bearer must not appear in audit line: %s", rawLine)
    require.False(t, regexp.MustCompile(`"(?:[^"]*?)":\s*"ek_[a-z2-7]{26}"`).MatchString(rawLine),
        "ek_ plaintext bearer must not appear in audit line: %s", rawLine)
    // credential_hash invariant: never present
    require.NotContains(t, rawLine, `"credential_hash":`, "credential_hash must not appear in audit line")
}
```
