|----------|-------------|
| Audit emission → log sink | Every audit event crosses from in-process Event struct to stdout JSON via slog; once on stdout, K8s log collection picks up |
| HTTP response → client | render.JSON/Error write bytes the client may persist; plaintext leakage here is permanent |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|

| T-03-02-02 | Information Disclosure | render.Error message field | mitigate | Caller passes hard-coded messages (per Hub §15.5 outcome map); error.message MUST NOT echo raw upstream errors or stack traces. Discipline enforced at handler plan-level (03-07..03-10) — this plan only provides the writer |
| T-03-02-03 | Tampering | audit constant value drift | mitigate | TestEventConstantsAreStable + TestEventConstantsMatchOrphan — string values are load-bearing for cross-phase log filtering |
| T-03-02-04 | Repudiation | audit emission failures | accept | slog handler errors are silent (Go convention); deployer monitors slog handler health out-of-band. ACH does NOT block requests on audit-write failures |
| T-03-02-05 | Denial of Service | json.Encoder unbounded body | mitigate | render.JSON callers MUST pass small structs (not user-controlled streams); the §15.5 envelope is always small. No length-cap needed at this layer; chi.Mux + http.Server.WriteTimeout (D-03) bound total bytes |
