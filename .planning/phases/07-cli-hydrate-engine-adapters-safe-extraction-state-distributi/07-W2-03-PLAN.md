For `exists-unowned`, run the three-tier cascade: (1) Eager byte comparison if Tier 1 bytes are already in memory (typical for prompt + scope-object artifact); (2) Lazy adapter `ResolveOutputContent()` if the file is adapter-merged (e.g. `.claude/.mcp.json`); (3) Lazy source-file read for pass-through resources where source.bin still lives in staging.       2. existingSha := sha256.Sum256(existingBytes)

      5. Tier 3: if sourceFn != nil → src, err := sourceFn(ctx, finalPath); on err return; sha := sha256.Sum256(src); return CascadeOutcome{Identical: ..., Tier: 3}, nil
